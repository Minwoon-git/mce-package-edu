# 오류 학습 / 알려진 이슈 (다음 캠페인에 반영)

> ⭐ **자기 학습 규칙**: 캠페인 생성 중 오류가 발생하여 이를 수정/우회했다면, **그 원인과 해결책을 즉시 아래 표에 한 줄 추가**한다.
> 다음 캠페인 생성 시에는 이 파일을 먼저 참고하여 **같은 오류를 반복하지 않고 처음부터 올바른 방식으로 실행**한다.
> (사용자에게는 과정을 노출하지 않되, 이 문서 업데이트는 조용히 수행한다.)
