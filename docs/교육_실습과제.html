진단 결과로 저니 만들기

지난 실습에서 고객 데이터를 진단했습니다. 이번에는 진단표에서 배정된 캠페인을 골라 정의서(xlsx)와 Draft 저니까지 만듭니다. 다 만들면 이 페이지 아래 '제출물 만들기'에서 파일을 첨부하고 제출 파일을 저장해 주세요.

  • 대상EDU01 · EDU02
  • 결과물정의서 xlsx · 분석 리포트 pptx · 캡처 · 검증 값
  • 저니 상태Draft로만 생성

할 일

챗봇에서 순서대로 진행합니다

  1. 1
    캠페인 고르기진단표에서 배정된 캠페인과 대상 인원을 확인합니다.
  2. 2
    '중간' 후보 선택후보 표에서 복잡도가 '중간'(분기 1개)인 번호를 입력합니다.
  3. 3
    수동 모드로 Plan진입 DE, 스케줄, 재진입, 단계, 대기를 하나씩 정합니다.
  4. 4
    정의서 확인 후 승인진행 방식은 '정의서 후 승인'. xlsx를 열어 본 뒤 승인합니다.
  5. 5
    Draft 저니 대조Journey Builder에서 저니를 열어 정의서와 같은지 봅니다.

  • 캡처

확인 필요 사항

  • 진입 DE 인원이 세그먼트 인원보다 적은가진입 대상은 세그먼트 중 수신동의한 사람만입니다. 같으면 동의 필터가 빠진 것이고, 많으면 조인에서 중복이 생긴 것입니다. 세그먼트 인원은 내 정답지(test_data/EDU0n/진단기대값.md)에 있습니다.
  • 이름이 모두 내 실습 ID로 시작하는가저니, 진입 DE, 이메일, Event Definition 모두 EDU01_ 또는 EDU02_로 시작해야 합니다.
  • 저니 상태가 Draft인가발행(Publish)하지 않습니다.

'제출물 만들기'에 저니 이름을 넣으면 위의 2번은 바로 판정해 줍니다.

          1. 시험 발송용 DE 만들기

          챗봇에 아래 문장을 보냅니다. EDU01은 내 실습 ID로, 내메일@milvus.co.kr은 내 메일 주소로 바꾸고, 2차시 저니를 골랐다면 '1차시'를 '2차시'로 바꿉니다. 챗봇이 DE를 만들고 내 행 1개를 넣어 줍니다.

          예시 · EDU01내 실습 ID는 EDU01이야. 1차시 저니의 진입 DE와 컬럼이 같은 시험 발송용 DE를 이름 끝에 _TEST를 붙여서 내 실습 ID 폴더에 발송 가능(Sendable)하게 만들어줘. 그리고 내 메일 주소 내메일@milvus.co.kr 으로 행 1개만 넣어줘. 수신동의는 Y, 회원 ID는 EDU01_TEST_01, 나머지는 임의 값으로.

          2. 내 행 확인하기

          1. Contact Builder → Data Extensions에서 내 실습 ID 폴더(예: EDU01)를 열고, 그 안의 _TEST DE를 엽니다.
          2. Records 탭에서 행이 1개뿐인지, 메일 주소가 내 주소이고 수신동의 값이 Y인지 봅니다.
          3. 분기 기준 칸(예: 장바구니 금액)의 값을 보고 Path A와 B 중 어느 쪽 메일이 올지 미리 짐작해 둡니다.

          3. 저니 수정 요청

          1번과 같은 대화창에서 이어서 보냅니다. 실습 ID는 1번에서 이미 알려 줬으니 다시 적지 않아도 됩니다. 2차시 저니를 골랐다면 '1차시'를 '2차시'로 바꿉니다.

          예시1차시 저니의 진입 DE를 내 _TEST DE로 바꾸고, 진입 일정은 1회 실행(Run Once)으로, 메일 앞에 대기가 있으면 5분으로 바꿔줘. 발행은 하지 마.

          4~5. 확인·발행·중지 (직접)

          1. Journey Builder에서 저니를 열고 맨 왼쪽 진입 소스를 눌러, 데이터 확장이 _TEST DE이고 일정이 Run Once인지 확인합니다.
          2. 메일 앞에 Wait가 있다면 5분인지 확인합니다. 다르면 화면에서 직접 고칩니다.
          3. 위의 '발행 전 확인 필요 사항'을 다시 보고, 오른쪽 위 Activate로 발행합니다.
          4. 메일을 다 받으면 저니 화면의 Stop으로 중지합니다.
