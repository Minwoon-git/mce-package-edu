# UrbanMall(어반몰) 샘플 데이터셋 (일반 이커머스 / 패션 쇼핑몰)

> ✅ **교육·데모용 가상 데이터입니다.**
> 프로그램으로 생성한 **합성 데이터**로, 실존 기업·인물과 무관합니다. 자유롭게 사용·수정·배포할 수 있습니다.
> - **이메일**: IANA 예약 도메인(`example.com` / `example.net` / `example.org`)만 사용 — 실수로 발송해도 외부에 도달하지 않습니다.
> - **휴대폰**: 미할당 국번 `010-0000-xxxx` 고정 — 실제 가입자에게 문자가 가지 않습니다.
> - 그래도 **실습 저니는 Draft로만** 두고, 발행 전 테스트 대상을 반드시 확인하세요.

STEP 0 스키마 분석 → **SFMC UI에서 CSV 업로드** → RAW DE 적재용 원천 CSV 5종.
기준일 **2026-09-04**, 회원 **3,000명**, 데이터 기간 **2022-01-01 ~ 2026-09-03**.

## STEP 0 실습 순서

1. 이 폴더의 `urbanmall_schema.sql`(또는 CSV 5종)을 첨부하고 "스키마 분석해줘"
2. **Phase A** — 원본 컬럼 개념 태깅·조인키 도출 → 핵심 컬럼 HITL 확인
3. **Phase B** — 빈 RAW DE(원본 컬럼명 그대로) + `analysis-guide/urbanmall.md` 자동 생성
4. **CSV 업로드** — SFMC UI에서 각 RAW DE에 직접 import (아래 참조)
5. STEP 1 "어떤 캠페인 만들 수 있어?" → 위 **진단 기대값 표**와 대조

### 4단계 — CSV 업로드 방법

Email Studio → Subscribers → **Data Extensions** (또는 Contact Builder → Data Extensions)

| # | 작업 | 값 |
|---|---|---|
| 1 | 대상 DE 선택 → **Import** | |
| 2 | 파일 선택 | 내 PC에서 직접 업로드 |
| 3 | 필드 매핑 | **Match by Header Row** — 헤더가 DE 컬럼명과 동일 |
| 4 | Data Action | **Overwrite** |
| 5 | 실행 → 건수 확인 | 위 표의 건수와 일치해야 함 |

**업로드 순서**: `MEMBER_INFO` · `ITEM_MST`(마스터) → `ORDER_MST` → `ORDER_ITEM` → `COUPON_ISSUE`

> ⚠️ 날짜는 `YYYY-MM-DD` / `YYYY-MM-DD HH:MM:SS` 형식이고 빈 값은 빈 칸입니다. 엑셀로 열었다가 저장하면 날짜 서식이 바뀌어 적재가 실패하니, **열어서 확인만 하고 저장하지 마세요.**
