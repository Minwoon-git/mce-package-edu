> ✅ **교육·데모용 가상 데이터입니다.**
> 프로그램으로 생성한 **합성 데이터**로, 실존 기업·인물과 무관합니다. 자유롭게 사용·수정·배포할 수 있습니다.
> - **이메일**: IANA 예약 도메인(`example.com` / `example.net` / `example.org`)만 사용 — 실수로 발송해도 외부에 도달하지 않습니다.
> - **휴대폰**: 미할당 국번 `010-0000-xxxx` 고정 — 실제 가입자에게 문자가 가지 않습니다.
> - 그래도 **실습 저니는 Draft로만** 두고, 발행 전 테스트 대상을 반드시 확인하세요.

## STEP 0 실습 순서

1. 이 폴더의 `urbanmall_schema.sql`(또는 CSV 5종)을 첨부하고 "스키마 분석해줘"
2. Phase A — 원본 컬럼 개념 태깅·조인키 도출 → 핵심 컬럼 HITL 확인
3. Phase B — 빈 RAW DE(원본 컬럼명 그대로) + GCS Import + `analysis-guide/urbanmall.md` 자동 생성
4. CSV 5개를 GCS 버킷에 업로드 → Import 실행 → RAW DE 적재 확인
5. STEP 1 "어떤 캠페인 만들 수 있어?" → 위 진단 기대값과 대조
